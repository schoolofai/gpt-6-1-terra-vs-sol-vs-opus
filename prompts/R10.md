Build a small playable top-down dungeon crawler game in a single self-contained file called index.html (plain HTML/CSS/JS, canvas, no external files or libraries).
Requirements:
- The player moves with the arrow keys AND WASD inside a walled dungeon room (walls block movement).
- At least 3 enemies that move and chase or patrol; touching an enemy costs health.
- The player can attack with Space (hits nearby enemies; enemies die after some hits) and killing enemies increases score. Collectible coins also add score.
- Show health and score on screen (HUD). When health reaches 0 show a "Game Over" screen with the final score; pressing R restarts with full health and score 0.
- For automated testing, expose window.game = { getState() } where getState() returns { player: {x, y}, health, score, gameOver, enemies: number }.
- No console errors. Do not ask questions; finish in one go.
